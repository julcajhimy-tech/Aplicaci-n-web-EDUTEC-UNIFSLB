# Proyecto Web: Escuela de Educación Tecnológica - UNIFSLB

Este proyecto es una aplicación web moderna desarrollada para la Escuela Profesional de Educación Tecnológica (Computación e Informática) de la Universidad Nacional Intercultural "Fabiola Salazar Leguía" de Bagua (UNIFSLB). La aplicación sirve como una presencia digital académica, mostrando la identidad institucional, la oferta académica por ciclos, trabajos destacados y una galería de actividades.

## ✨ Características Principales

- **Diseño Moderno y Responsivo:** Interfaz limpia y adaptable a cualquier dispositivo, construida con Tailwind CSS.
- **Portada Dinámica:** Sección de bienvenida (`Hero`) con un video de fondo para un mayor impacto visual.
- **Componentes Reutilizables:** Arquitectura basada en componentes de React para facilitar el mantenimiento y la escalabilidad.
- **Gestión de Contenido Centralizada:** Toda la información del sitio (textos, enlaces, datos de la galería) se gestiona desde `src/data/siteContent.js`, facilitando futuras actualizaciones.
- **Secciones Dinámicas:**
  - **Ciclos Académicos:** Muestra información relevante para cada ciclo formativo.
  - **Portafolios Grupales:** Tarjetas que enlazan a trabajos y portafolios de estudiantes.
  - **Trabajos Destacados:** Sección para resaltar proyectos específicos, con enlaces a demostraciones externas.
  - **Galería de Actividades:** Galería de imágenes con sistema de filtros por categoría y vista ampliada (lightbox).

## 🚀 Tecnologías Utilizadas

- **Framework Frontend:** [React](https://reactjs.org/)
- **Entorno de Desarrollo:** [Vite](https://vitejs.dev/)
- **Estilos CSS:** [Tailwind CSS](https://tailwindcss.com/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM](https://reactrouter.com/)
